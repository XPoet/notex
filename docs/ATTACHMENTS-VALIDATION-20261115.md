# 附件资源存储改造验收记录

日期：2026-11-15。平台：macOS。

## 实现范围

- 支持图片及 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX 的文件粘贴、选择与拖入。macOS 文件剪贴板优先读取原始文件 URL，保留原始字节和文件名。
- 图片显示预览与文件名；文档显示图标、文件名及大小。正文继续保存标准 Markdown 引用。
- 新资源存放在 `assets/<笔记ID>/<资源ID>.<扩展名>`。不同笔记保存独立副本，笔记改名不移动资源。
- 附件支持默认应用打开、文件管理器定位和另存为；从笔记移除只删除当前引用，支持撤销，文件随笔记永久删除清理。
- 导出及自动备份仅包含正文实际引用的资源。含附件笔记按笔记名创建目录，Markdown 与附件同目录，链接使用相对路径。
- V005 新增迁移允许通用附件。旧共享图片逐关联复制、校验并切换正文、摘要、索引和恢复草稿，原文件保留，缺失文件保留旧引用并允许下次启动重试。

## 使用边界

- 单个附件上限 100 MiB。
- 原生文件 URL 剪贴板桥接当前面向 macOS；其他平台保留文件选择、拖入及 WebView 提供的 File 粘贴入口。
- 移除引用不会即时删除磁盘文件；旧版迁移原文件保留用于恢复。
- 本次真实桌面默认应用验收覆盖 PDF；Word、PPT、Excel 的格式处理与接口由自动测试及浏览器交互验证，未分别启动 Office 软件。
